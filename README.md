# AI Advent Challenge — День 1

Минимальный Go-сервер, который отправляет запрос в LLM (DeepSeek API), получает ответ и показывает его в браузере.

## Что внутри

- Go-сервер на стандартной библиотеке, без внешних зависимостей.
- `POST /api/chat` — проксирует запрос в DeepSeek, ключ остаётся на сервере.
- `GET /` — чат-интерфейс (встроен в бинарник через `embed`).
- `GET /healthz` — проверка, что сервер жив.
- Ключ API читается из отдельного файла `api_key.txt`, который добавлен в `.gitignore`.

## Запуск

1. Вставьте свой ключ DeepSeek в файл `api_key.txt` (только ключ, без кавычек):

   ```
   sk-...
   ```

   Ключ можно получить на https://platform.deepseek.com/api_keys

2. Запустите:

   ```powershell
   go run .
   ```

3. Откройте http://localhost:8080

## Сборка бинарника

```powershell
go build -o bin/app.exe .
.\bin\app.exe
```

## Настройки (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DEEPSEEK_API_KEY_FILE` | `api_key.txt` | Путь к файлу с ключом |
| `DEEPSEEK_API_KEY` | — | Ключ через переменную окружения (приоритетнее файла) |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | Базовый URL API |
| `DEEPSEEK_MODEL` | `deepseek-chat` | Модель |
| `PORT` | `8080` | Порт сервера |

## Тесты

```powershell
go test ./...
```

## Безопасность

- `api_key.txt`, `.env` и `*.key` исключены из git.
- Ключ не попадает в браузер: фронтенд общается только со своим сервером.
- Размер запроса ограничен 1 МБ, ответа — 2 МБ.
